# Sanatan Samvad — Redesign

यह static GitHub Pages-ready website है।

## लगाना कैसे है
1. इस ZIP को extract करें।
2. `index.html`, `style.css`, `script.js` और `assets` folder को अपने GitHub repository के root में रखें।
3. पुराने `index.html` और `style.css` को replace करें (पहले backup लेना बेहतर है)।
4. GitHub Pages में बदलाव publish होने के बाद वेबसाइट refresh करें।

## कहाँ क्या बदलना है
- `assets/hero-wide.png` — मुख्य cover/banner
- `assets/logo.png` — लोगो
- `assets/story-ram.png`, `assets/darshan.png`, `assets/about-shiv.png` — content cards/sections
- `index.html` — headlines, categories और links
- `style.css` — पूरा रंग/डिजाइन

अभी news text demo/placeholder है; अपनी असली खबरों और links से बदल सकते हैं।
